Protocol Detector

Описание

Protocol Detector — это инструмент для автоматического распознавания протоколов, проверки доступности сервисов и авторизации по заданным учетным данным.
Программа поддерживает работу через графический интерфейс (Tkinter) и формирует подробные отчёты в формате JSON.

'ssh': 22,
'telnet': 23,
'http': 80,
'https': 443,
'winrm_http': 5985,
'winrm_https': 5986,
'netconf': 830,
'rdp': 3389,
'vnc': 5900,

Поддерживаемые протоколы

Запустите программу: 
dist/GF.exe 
В окне программы введите: 
IP / Домен (например, 192.168.1.10) 
Логин (например, admin) 
Пароль 
Нажмите кнопку "Проверить". 
В нижней части окна появится JSON-отчёт со следующей информацией: 
Список проверенных портов и протоколов. Полученные баннеры сервисов. 
Попытки подключения (успех/ошибка). 
Выбранный протокол для работы. 
Время проверки. 
Если сервис требует 2FA (одноразовый код) — программа отобразит запрос, введите код вручную. 
Для RDP на Windows откроется стандартное окно подключения mstsc.

Программа может требовать 2FA когда на самом деле 2FA не требуется, в таком случае достаточно нажать 'Ок' и дождаться окончания работы программы.
